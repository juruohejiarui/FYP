# Stage 3: Turn Planning — 话轮规划

你是一个对话结构规划器。为改写后的线下门诊对话设计话轮骨架。**只输出JSON，不要过度思考。**

## 输入格式

```json
{
  "original_dialogue": { ... },
  "fact_lock": { ... },
  "scene_adaptation": { ... }
}
```

## 输出格式

```json
{
  "turn_plan": [
    {"speaker": "医生", "intent": "开场问候", "keep": []},
    {"speaker": "患者", "intent": "主诉", "keep": ["头晕", "一个多月"]},
    {"speaker": "医生", "intent": "追问特点", "keep": ["怎么晕"]},
    {"speaker": "患者", "intent": "回答", "keep": ["昏昏沉沉"]}
  ],
  "patient_level": "layperson",
  "persona": {"patient": "年轻女性，有点焦虑", "doctor": "中年医生，说话简洁"}
}
```

- **turn_plan**: 按顺序排列的话轮。speaker 只能是"医生"或"患者"。intent 简短描述意图（不写具体症状名，写对话节奏如"开放式追问""确认重点"）。keep 只放必须显式确认的关键事实（重要诊断、风险信息、药名），最多2个。常规症状不放keep——会通过开放式提问自然引出。
- **patient_level**: "layperson"（普通患者）或 "experienced_patient"（长期患者，懂一些术语）
- **persona**: 简短的角色特征描述

## ⚠️ 核心规则：不要逐症状规划

**turn_plan 中不要出现具体症状名。** 用 intent 描述对话节奏，不是症状清单。keep 只放必须显式确认的关键事实（重要诊断、风险信息、药名），不放常规症状。

❌ 错误做法（症状清单）:
```
{"speaker":"医生","intent":"问痛经","keep":["痛经"]}
{"speaker":"患者","intent":"答","keep":["有痛经"]}
{"speaker":"医生","intent":"问白带","keep":["白带"]}
{"speaker":"患者","intent":"答","keep":["白带多"]}
{"speaker":"医生","intent":"问心慌","keep":["心慌"]}
... (每个症状一个Q&A = 不合格)
```

✅ 正确做法（对话节奏）:
```
{"speaker":"医生","intent":"开放式主诉","keep":[]}
{"speaker":"患者","intent":"说出主要不适","keep":["头晕","四肢无力"]}
{"speaker":"医生","intent":"追问主诉细节","keep":["怎么晕"]}
{"speaker":"患者","intent":"描述细节","keep":["昏昏沉沉"]}
{"speaker":"医生","intent":"开放式追问","keep":[]}
{"speaker":"患者","intent":"说出关联症状组","keep":["痛经","白带多"]}
{"speaker":"医生","intent":"确认重点","keep":["痛经严重吗"]}
{"speaker":"患者","intent":"详细描述","keep":["有时候痛得厉害"]}
{"speaker":"医生","intent":"开放式追问","keep":[]}
{"speaker":"患者","intent":"补充另一组","keep":["脚痛","出气困难"]}
```
**症状收集阶段只用 3-5 个医生turn（含开放式+确认式），不是每个症状一个turn。**

## 硬约束

1. **医生的每个提问 turn 只能问一个问题。** "宝宝肚子胀吗？大便干吗？费劲吗？" = 不合格。一问一答拆成多个 turn。
2. 同一说话人不能连续两 turn
3. 每个 turn 的 keep 最多 2 个要点
4. **医生的诊断/解释每个 turn 只说一个要点**
5. **交替使用开放式和确认式提问。** 开放式让患者展开（"还有什么不舒服？"），确认式核实具体点（"那痛经严重吗？"）。不能100%确认式，不悬殊即可。关联症状分组追问。
6. **医生的追问必须有上下文。** 每次追问必须基于患者刚说的内容或医学常识自然延伸。不能凭空问患者没提过的症状。如患者说"喘不上气"→追问"喉咙有痰吗？"是自然的（呼吸关联）。患者刚说"头晕"→突然问"心慌吗？"是不自然的，需先铺垫"头晕和心脏也有关系"。
7. 连续追问必须变换句式，不能重复
8. 必须有开场和结尾

## 追问变化参考

- "嗯，然后呢？" / "这样啊，还有吗？" / "哦，继续说。" / "好的。还有什么？"
- **禁止三连重复：** "还有吗？" → "还有别的吗？" → "还有其他的吗？"

## patient_level

- **layperson**: 普通初诊患者，症状描述含糊，需要医生引导
- **experienced_patient**: 长期慢病/复诊患者，能说出一些术语和药名

## 正例

**输入：** 多症状门诊对话

**正确输出（用对话节奏，不用症状清单）：**
```json
{
  "turn_plan": [
    {"speaker": "医生", "intent": "开场问候", "keep": []},
    {"speaker": "患者", "intent": "主诉", "keep": ["头晕", "一个多月"]},
    {"speaker": "医生", "intent": "追问主诉特点", "keep": ["怎么晕"]},
    {"speaker": "患者", "intent": "描述", "keep": ["昏昏沉沉"]},
    {"speaker": "医生", "intent": "开放式追问", "keep": []},
    {"speaker": "患者", "intent": "说出关联症状组", "keep": ["恶心呕吐","耳鸣"]},
    {"speaker": "医生", "intent": "确认重点", "keep": ["耳鸣什么样"]},
    {"speaker": "患者", "intent": "详细描述", "keep": ["像敲东西的声音"]},
    {"speaker": "医生", "intent": "开放式追问", "keep": []},
    {"speaker": "患者", "intent": "补充其他症状", "keep": ["睡眠差","精神紧张"]},
    {"speaker": "医生", "intent": "诊断解释", "keep": ["与熬夜相关"]},
    {"speaker": "患者", "intent": "确认理解", "keep": []},
    {"speaker": "医生", "intent": "医嘱", "keep": ["调整作息"]},
    {"speaker": "患者", "intent": "感谢", "keep": []}
  ],
  "patient_level": "layperson",
  "persona": {"patient": "年轻男性，回答简短", "doctor": "内科医生，追问仔细"}
}
```
**注意：keep 中没有逐个列症状（痛经、白带、心慌…），只放了关键点（主诉、重要特征）。常规症状通过"开放式追问"自然引出。**

## 反例

### 反例 1: 重复追问

```json
{"speaker": "医生", "intent": "追问", "keep": []},
{"speaker": "医生", "intent": "再追问", "keep": []},
{"speaker": "医生", "intent": "继续追问", "keep": []}
```
❌ 连续三个医生 turn 且追问句式重复。

### 反例 2: keep 超载

```json
{"speaker": "患者", "intent": "罗列症状", "keep": ["头晕", "无力", "心慌", "脚痛", "出气困难", "全身重"]}
```
❌ 6个要点挤在一个 turn。拆成 3 个 turn 各 2 个。

### 反例 3: 多问题

```json
{"speaker": "医生", "intent": "同时问熬药和症状", "keep": ["方便熬药", "有什么症状"]}
```
❌ 一个 turn 两个问题，患者不知道该先答哪个。拆成两个 turn。
